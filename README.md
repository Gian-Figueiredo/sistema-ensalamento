# Sistema de Ensalamento

Sistema web para gerenciamento e alocação de espaços físicos acadêmicos, desenvolvido para integração com plataformas institucionais baseadas em **Joomla 3.10**.

A solução tem como objetivo centralizar o gerenciamento de ambientes, horários, turmas e demais informações relacionadas à ocupação de espaços físicos, proporcionando maior organização, controle e eficiência nos processos de ensalamento.

## Sobre o projeto

O Sistema de Ensalamento é uma aplicação voltada a instituições de ensino que necessitam gerenciar a distribuição e a utilização de seus espaços físicos.

Desenvolvido considerando a arquitetura do Joomla 3.10, o sistema busca aproveitar os recursos oferecidos pelo CMS, mantendo integração com o ambiente institucional e respeitando sua estrutura de extensões, permissões e gerenciamento de usuários.

O projeto contempla desde o levantamento e análise de requisitos até o desenvolvimento, testes e validação da solução.

## Objetivos

- Centralizar as informações relacionadas aos espaços físicos institucionais.
- Facilitar o gerenciamento de salas e ambientes acadêmicos.
- Organizar a alocação de espaços conforme horários e demandas.
- Reduzir conflitos de ocupação e inconsistências no ensalamento.
- Proporcionar uma interface integrada ao ambiente institucional.
- Facilitar a manutenção e a evolução do sistema.

## Arquitetura e integração

A aplicação é projetada para funcionar integrada ao Joomla 3.10, utilizando sua estrutura de desenvolvimento para organizar funcionalidades e recursos.

A implementação pode utilizar os mecanismos nativos do Joomla, como:

- Componentes para funcionalidades principais do sistema.
- Módulos para apresentação de informações em diferentes áreas.
- Plugins para integração e extensão de funcionalidades.
- Sistema de autenticação e gerenciamento de usuários.
- Modelo de permissões e níveis de acesso do Joomla.

Essa abordagem permite manter a solução organizada e alinhada às convenções de desenvolvimento da plataforma.

## Funcionalidades previstas

As funcionalidades do sistema podem ser organizadas nos seguintes módulos:

- **Gerenciamento de espaços:** cadastro, consulta e atualização de salas e ambientes.
- **Gerenciamento de horários:** organização dos períodos disponíveis para utilização dos espaços.
- **Gerenciamento de ocupações:** controle da utilização dos ambientes.
- **Alocação de espaços:** associação de demandas acadêmicas aos espaços disponíveis.
- **Consulta de ensalamento:** visualização das informações de ocupação.
- **Controle de acesso:** gerenciamento das permissões dos usuários.

As funcionalidades serão detalhadas e refinadas durante a etapa de análise de requisitos.

## Organização do desenvolvimento

O desenvolvimento do projeto está dividido em quatro etapas principais:

### 1. Análise de requisitos
Levantamento das necessidades do sistema, identificação dos usuários, definição das funcionalidades e documentação dos requisitos funcionais e não funcionais.

### 2. Projeto de arquitetura
Definição da arquitetura da aplicação, modelagem do banco de dados, organização dos componentes e planejamento da integração com o Joomla 3.10.

### 3. Desenvolvimento e testes
Implementação das funcionalidades, integração com a plataforma, criação das interfaces e execução de testes para verificar o comportamento do sistema.

### 4. Validação
Verificação da conformidade da aplicação com os requisitos definidos, identificação de possíveis inconsistências e avaliação dos resultados obtidos.

## Requisitos para execução

Para executar o sistema, recomenda-se um ambiente compatível com Joomla 3.10, contemplando:

- Servidor web Apache ou Nginx.
- PHP em versão compatível com Joomla 3.10.
- Banco de dados MySQL ou MariaDB em versão compatível.
- Instalação funcional do Joomla 3.10.
- Permissões adequadas para instalação e execução de extensões.

**Observação:** Joomla 3.10 está fora do período de suporte oficial. Para ambientes de produção, recomenda-se avaliar os riscos de segurança e considerar uma versão atualmente suportada do Joomla.
